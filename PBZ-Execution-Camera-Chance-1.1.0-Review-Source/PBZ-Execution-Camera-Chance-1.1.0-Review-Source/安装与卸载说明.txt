影之刃零 · 处决特写概率 1.1.0 独立版

安装：
1. 退出游戏，完整解压 ZIP。
2. 双击 PBZ-Execution-Camera-Manager.exe。
3. 自动查找或手动选择 PBZ 根目录（内含 platform 文件夹）。
4. 设置 0–100% 概率，点“安装 / 更新”，随后从 Steam 启动游戏。

改概率：
再次打开程序，设置数值后点“保存概率”。默认 15%，支持一位小数。
0% = 普通敌人不出特写；100% = 保留普通敌人全部特写。
Boss 保留原有特写。处决动作、伤害、奖励照常。
游戏运行中保存后，在游戏内按 Ctrl+Alt+F6 生效；重启游戏也会自动读取。

卸载（包含配置）：
退出游戏 → 打开同一程序 → 选择游戏目录 → 点“彻底卸载（含配置）”。
删除本 Mod 的脚本、配置、启用标记、安装记录和旧代码备份。
本程序独占安装且未改动的加载器可自动清理；共用或既有加载器会保留。
血条 Mod 和其他 Mod 的文件及设置会保留。
管理器是便携程序，无注册表、AppData 或后台服务；卸载后可自行删除本发布包。

内置加载器，可独立安装，无需先安装血条 Mod、Python 或编译器。
适配 Windows 10/11 x64（.NET Framework 4.8）与 Steam build 26266538 / CL-301524_JKS-17219。
若提示没有游戏目录写入权限，右键程序，以管理员身份运行后重试。
遇到不同版本的已有加载器，安装会停止，不会直接覆盖。
更多兼容性说明、手动卸载方法和验证范围见 README.md。
