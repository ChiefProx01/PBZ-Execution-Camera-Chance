# 影之刃零：处决特写概率 1.1.0 独立版

用窗口程序调整普通敌人处决特写的播放概率，支持 **0–100%**，默认 **15%**。Boss 保留原有特写。处决动作、伤害和奖励按原有行为执行，RB 继续使用游戏中的按键绑定。

本包已内置适配加载器，**不需要血条 Mod，也不包含血条 Mod**。安装不需要 Python、编译器、联网下载或手动配置加载器。适配 Windows 10/11 x64，使用系统自带的 .NET Framework 4.8。

## 安装与设置

1. 正常退出游戏，把下载的 ZIP **完整解压**到任意文件夹。
2. 双击 **PBZ-Execution-Camera-Manager.exe**。
3. 程序会尝试从 Steam 查找游戏。若没有找到，点击“选择目录”，选择 **PBZ 游戏根目录**（内含 `platform` 文件夹）。
4. 拖动滑块或输入 0–100 的数值，点击 **安装 / 更新**。
5. 显示安装完成后，从 Steam 启动游戏。

之后随时重新打开该程序，修改数值并点击 **保存概率**。支持一位小数。

- **0%**：已识别普通敌人的处决不播放特写。
- **15%**：默认值，每次处决有 15% 概率保留特写。
- **100%**：保留普通敌人原有处决特写。
- **Boss**：始终保留原有特写，不参与概率判定。

保存时若游戏已经启动，切回游戏按 **Ctrl+Alt+F6** 重新读取配置；下一次启动也会自动读取。同一次处决的前置动作和后续动作共用一次判定。概率逐次随机，不保证每隔固定次数播放。

程序会读取已有配置。更新时使用窗口显示的概率，保留配置中的其他字段。已有血条 Mod 和其他 Mod 的文件、配置不会被改动。

## 彻底卸载

1. 正常退出游戏。
2. 再次打开 **PBZ-Execution-Camera-Manager.exe**，选中相同游戏目录。
3. 点击 **彻底卸载（含配置）**，确认即可。

卸载会删除整个 `platform\steam\ue4ss\Mods\PBZExecutionCameraChance`，包括脚本、配置、启用标记、安装记录和本 Mod 的旧版代码备份，并清理 `mods.txt` 中本 Mod 的条目。

若加载器由本程序从零安装、没有其他 Mod 使用、其文件未被改动，程序也会清理该加载器和已知的运行日志。既有加载器、其他 Mod 共用的加载器或包含新增文件的加载器会保留。程序不会删除其他 Mod。

管理器是便携程序，不写注册表或 AppData，不安装后台服务。完成卸载后可自行删除下载、解压的发布包。请保留此程序，以便以后设置或卸载；再次下载同版也可以操作。

若无法运行程序，可在退出游戏后手动删除上面的 `PBZExecutionCameraChance` 文件夹，并删除 `mods.txt` 中以 `PBZExecutionCameraChance :` 开头的条目，即可移除本 Mod 和配置。共用加载器应保留。

## 兼容性

- 当前仅验证 **Steam build 26266538 / CL-301524_JKS-17219**。程序会拒绝在不同游戏版本上安装；游戏更新后仍可卸载。
- 内置 **UE4SS v3.0.1-1183-gcdbc0b66** 的 PBZ 适配版本。遇到不同版本的已有加载器，程序会停止安装并指出冲突文件。
- 默认跳过特写时也抑制该次处决时间线内的镜头震动，不改变普通战斗镜头。
- 无法确认类型的目标或未知镜头结构会保留原有表现。多目标处决中包含已识别 Boss 时，整组保留原镜头。
- 适配全部武器的公共处决入口，不按武器名称过滤；尚未逐一实测所有武器、Boss、空中或潜行处决。

实机验证已包括斩马刀的 0% / 100% 分支、双刀的 0% 分支，以及残钢刃对 `Standard` 普通敌人的 0% 回归；处决动作正常。1.1.0 沿用该已验证的镜头处理逻辑，新增独立管理器及完整依赖包。
